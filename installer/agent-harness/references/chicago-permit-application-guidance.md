# Chicago permit application guidance for STUDIO QAQC engagements

Shared reference across projects. Recorded 2026-10-09 from City of Chicago published instructions. This is not a project compliance determination or permission to submit, certify, or stamp.

## Scope and source precedence

The selections below apply specifically to **Building Rehabilitation under Standard Plan Review in the legacy Hansen Dynamic Portal**. Do not apply them automatically to new construction, Self-Certification, Developer Services, Express Permits, or a replacement portal. Confirm the project workflow and consult the matching current City instructions before advising on a field. Dropdown labels alone are not reliable evidence of the intended selection.

The City explains that the legacy portal retains terminology predating the 2019 Construction Codes. Its published instructions deliberately prescribe placeholder values. Preserve actual classifications and project facts in the description, drawings and Form 400; do not substitute portal placeholders there.

## Required legacy portal selections

| Field | City-prescribed value for this workflow |
| --- | --- |
| Initial application type | Renovations/Alterations/Additions with Plans |
| Workbenches | Architectural Work only |
| Review Program | Standard Plan Review |
| Type of Permit | Commercial Construction, even for residential occupancy |
| Scope of Work | Renovation of Structure |
| Occupancy Code and Existing Occupancy Code | J-Misc Buildings/Structures in both fields |
| Floors Worked On | 1 |
| Commercial Units Worked On | 1 |
| Building Volume | 1 |
| Construction Class | 4B - Combistible Frame Construction, as labeled in the instructions |

The last six entries are prescribed regardless of actual classifications/counts/volume. Building/Tent Area must instead reflect calculated work area; building height must reflect the building-code measurement rounded to a whole foot. Zoning information must reflect actual Title 17 information. Follow the source for other fields to leave blank and certificate-of-occupancy questions. [S1]

**Lesson from the initial review:** advising Residential Construction because the building is residential, or Alteration of Structure because partitions change, was incorrect for this workflow. The original Commercial Construction / Renovation of Structure selections were supported by the City. Read the full workflow-specific instructions before interpreting individual dropdowns.

## Description requirements

For this workflow, begin with **SPR 2019 CBRC:**. Describe the work, stories above grade, dwelling/sleeping-unit counts and affected units where applicable, and accessory structures included. End with actual occupancy group(s) and construction type. [S2]

Drafting template, requiring project-specific completion:

> SPR 2019 CBRC: [WORK AND LOCATION] IN AN EXISTING [STORIES ABOVE GRADE]-STORY [BUILDING USE AND UNIT COUNT] BUILDING [WITH BASEMENT IF APPLICABLE]. [AFFECTED UNITS OR COMMON AREAS, PRINCIPAL WORK AND INCLUDED ACCESSORY STRUCTURES]. [ACCURATE OCCUPANCY/UNIT-COUNT CHANGE STATEMENT]. (EXISTING AND PROPOSED OCCUPANCY GROUP(S) [ACTUAL GROUPS]; TYPE [ACTUAL TYPE] CONSTRUCTION.)

Do not automatically assume R-2, IIIA, unchanged occupancy, no added unit, accessory basement use, or a particular rehabilitation method. Establish these from the project evidence and architect's decisions. Portal, Form 400 and drawing descriptions must be coordinated.

## Application and submission checklist

- Read the complete matching application instructions, not only a search excerpt. Match address, PINs, cost including labor/materials, work area, description, zoning, contacts and contractor information across records. Check source instructions before Finish; they warn that application data other than contractors cannot then be edited through that workflow. [S1]
- Read the City's drawing checklist: index, zoning and construction-code information, applicable editions, professional statements, applicable approvals, title blocks, revision history/clouds, dimensions, graphic/text scales, room uses, north arrows, existing/proposed distinctions, and appropriate site plan. Leave the upper-right 3-by-3-inch stamp space. Professional execution remains the architect's responsibility. [S3]
- Prepare separate single-sheet drawing PDFs, unlocked and free of comments/hidden layers. Use permitted sizes and landscape orientation. Filenames are limited to 75 characters, use only allowed characters (no underscores), and end with the actual application number. Drawing names include sequence, sheet designation and descriptive title. Document/reference files have separate sizing and naming rules. Apply the plan-based section, not Express Permit examples. The source has inconsistent 9/10-digit wording; use the assigned number and resolve validator discrepancies. [S4]
- Review the current forms directory for Form 400, applicable energy documentation and conditional supporting forms. A listed form is not automatically required. Form 401GC is listed for applicant-as-GC; Form 402 is excavation certification. Do not repeat obsolete form references from older PDFs. [S5]
- Complete the Applicant Upload task after uploading to appropriate ProjectDox folders. Resolve screening, discipline/zoning comments, holds, contractor information and final fees. Download the issued certificate and released drawings and meet posting/site-copy requirements. [S6]

These notes summarize application/submission instructions. They do not exhaust Chicago zoning, rehabilitation, accessibility, energy, fire/life-safety, structural, MEP, environmental, or specialty permit requirements. Verify applicable technical provisions against the actual project before giving advice. Never call a project compliant or ready to stamp on the basis of this reference.
